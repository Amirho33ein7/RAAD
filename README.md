# رَعد | RAAD

**شعار:** نبض رنک، زیر نظر تو ⚡

رعد یک همراه مستقل و فارسی‌زبان برای بازیکنان Call of Duty: Mobile است. هدف نسخهٔ آغازین، ساخت یک پایهٔ واقعی و قابل توسعه برای نمایش داده‌های پروفایلِ قابل دریافت، ثبت تاریخچهٔ رنک و مدیریت شخصی کلیپ‌هاست.

> این پروژه مستقل و غیررسمی است و وابستگی یا تأیید رسمی Activision را ادعا نمی‌کند. API عمومی مورد استفاده نیز غیررسمی است و ممکن است ناپایدار باشد.

## وضعیت فعلی

این مخزن برای پیاده‌سازی مرحله‌ای اپ آغاز شده است. تا زمانی که endpoint واقعی آزمایش نشده، هیچ اطلاعات بازیکنی واقعی یا دسترسی کامل به آمار بازی تضمین نمی‌شود.

## ساختار هدف

- `app/` — اپ اندروید Flutter با رابط فارسی و راست‌چین
- `backend/` — API با FastAPI برای اتصال کنترل‌شده به سرویس پروفایل و تاریخچهٔ رنک
- `docs/` — مستندات نصب، محدودیت‌ها و حریم خصوصی
- `.github/workflows/` — بررسی خودکار پایه

## قابلیت‌های برنامه‌ریزی‌شده

- جست‌وجوی پروفایل با نام یا شناسه، تنها با فیلدهای واقعاً برگشتی از منبع
- ثبت snapshotهای رنک از زمان اتصال
- مقایسهٔ دو پروفایل بر اساس داده‌های مشترک و قابل‌دسترسی
- کتابخانهٔ خصوصی کلیپ‌های کاربر (پس از پیکربندی امن Firebase)
- منوی همبرگری و رابط فارسی RTL

## API غیررسمی مورد بررسی

مستندات: https://github.com/Harry260/codm-api

Base URL مستندشده: `https://callofdutymobile.vercel.app`

این منبع قبل از استفاده باید از نظر دسترس‌پذیری، پاسخ واقعی، محدودیت نرخ و شرایط استفاده بررسی شود. هیچ رمز عبور Activision نباید دریافت یا ذخیره شود.

## فناوری‌های هدف

- Flutter / Dart
- Python / FastAPI
- PostgreSQL
- Firebase Authentication و Firebase Storage (نیازمند پیکربندی توسط مالک پروژه)

## وضعیت ادغام

اتصال به سرویس خارجی، Firebase و دیتابیس باید با تنظیمات واقعی و تست اجرا تأیید شود. وجود کد به‌تنهایی به معنی فعال بودن سرویس بیرونی نیست.

## اجرای Backend

در پوشهٔ `backend` فایل `.env.example` را به `.env` کپی کن و مقادیر لازم را تنظیم کن. سپس:

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

مستندات محلی API پس از اجرا در `/docs` در دسترس است.

## اجرا و تست اپ

پس از نصب Flutter SDK:

```bash
cd app
flutter pub get
flutter run
```

## حریم خصوصی

پروفایل‌های جست‌وجوشده نباید به‌عنوان حساب‌های تأییدشده تلقی شوند. کلیپ‌ها باید خصوصی باشند مگر آنکه کاربر آگاهانه قابلیت انتشار را فعال کند. اسرار و کلیدهای Firebase را در Git قرار ندهید.

## سلب مسئولیت

Call of Duty: Mobile و Activision متعلق به صاحبان مربوطه هستند. رعد پروژه‌ای مستقل و غیررسمی است.
